# Paper Folding Creations Website

An interactive website that demonstrates the art of paper folding to create useful objects, featuring virtual paper folding simulations and step-by-step crafting tutorials.

![Paper Folding Creations Preview](https://img.shields.io/badge/Preview-Paper%20Folding-blue)
![License](https://img.shields.io/badge/License-MIT-green)

## 🎯 Features

- **Interactive Paper Folding Simulation**
  - Virtual paper that responds to user interaction
  - Visual fold lines and transformations
  - Real-time feedback on folding status

- **Useful Object Gallery**
  - Four practical paper creations with difficulty ratings
  - Paper organizer, gift box, bookmark corner, and phone stand
  - Hover effects and visual engagement

- **Step-by-Step Tutorial**
  - Detailed instructions for creating a paper organizer
  - Numbered steps with clear explanations
  - Beginner-friendly crafting guide

- **Responsive Design**
  - Mobile-friendly layout
  - Adapts to different screen sizes
  - Clean and intuitive interface

## 🎮 Interactive Elements

- **Fold Paper Button**: Toggles between flat and folded paper states
- **Reset Button**: Returns the paper to its original flat state
- **Create Object Button**: Transforms folded paper into a practical object
- **Clickable Paper**: Click directly on the paper to fold/unfold
- **Hover Effects**: Object cards respond to mouse hover
